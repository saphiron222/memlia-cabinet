# Matrice d’interface Teradion → Memlia

Préparation au 17 octobre 2026 à partir du corpus conservé, complétée par une consultation interne en lecture de 30 vues le même jour. Aucun changement applicatif n’est attesté par ce document. Autorité : [exigences](exigences.json), **66 familles, 171 identifiants : 160 requis, 10 exclus, 1 extension proposée**. Les identifiants ci-dessous gardent leur propriétaire; aucun changement de périmètre. Cette matrice décrit une cible, pas une livraison.

Memlia reste une application hébergée au cabinet, ouverte dans un navigateur. Conserver les espaces, sous-menus, grilles métier, fiches et actions de Teradion. La nouvelle demande place **Plane en référence principale** : navigation structurée, en-têtes, onglets, listes, Kanban et barres d’outils. Éviter une collection uniforme de cartes monochromes : distinguer navigation, surface de travail, propriétés et états avec la hiérarchie des références. Les accents d’état conservent leur sens métier et un libellé accessible.

**P** = [Plane : navigation](https://docs.plane.so/workspaces-and-users/customize-navigation), [listes, tableaux, vues et filtres](https://docs.plane.so/core-concepts/views). **T** = [Twenty : table, fiche et panneau de propriétés](https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/getting-started/core-concepts/layout.mdx). **C** = [cal.diy](https://www.cal.diy/) pour calendrier, réglages et formulaires, avec [source primaire](https://github.com/calcom/cal.diy). Ce sont des responsabilités de conception choisies; aucun rendu Memlia ni examen visuel complet de ces applications n’est attesté ici. Les composants/versions amont font l’objet d’une recherche distincte.

**D** : documenté (guide, annonce ou démo enregistrée); **O** : réellement observé dans le corpus conservé, uniquement dans la portée indiquée; **L** : choix/contrat local, sans preuve du comportement Teradion. D/O ne certifient pas un scénario complet. Les liens « guide » visent les URL de documentation officielles; leur lecture provient des copies conservées, leur accès public sans session n’est pas confirmé. Les pages vitrines prouvent une annonce. Pour L, le lien fournit une origine ou référence, jamais une preuve d’écran original.

## Parcours complets à préserver

Ces enchaînements sont des cibles fonctionnelles issues des guides ci-dessus; seule la séquence de tâche possède une exécution interne bornée.

1. **TVA** : Échéances → TVA → année/mois et périmètre → matrice dossier × jours → cellule → déclaration, origine et fraîcheur → checklist/pièces/commentaires → demande d’approbation → résultat interne → retour source et export. Garder approbation, déclaration et paiement distincts. P pour grille/barre; T pour détail. La grille et les quatre onglets du détail ont été revus en lecture le 17 octobre ; l’approbation et les actions externes n’ont pas été exécutées.
2. **Bilan** : paramètres → année/famille/étapes et droits → Bilans → dossier → étape → état/date/pièces → filtres/dépôt → préparation année suivante. P pour matrice; T pour cellule/fiche; C pour configuration. Ne pas déduire un dépôt externe d’une marque interne.
3. **Process personnalisé** : personnalisation → cible et population → colonnes/types → création → sous-menu Suivi propre → ligne → état/date. Variante périodique : Dossier/Contact et fréquence de chaque colonne; variante échéance : règle/groupe → aperçu → liaison → occurrences → pause/régénération des vierges. P/T/C; cible définitive documentée, création non exécutée.
4. **Tâche** : liste → type/nom/affectation → créer → fiche → renommer → En cours → checklist → Fait → afficher terminées → recharger → Excel/CSV. O limité à une tâche fictive; récurrence seulement prévisualisée. Date non retrouvée et répétition d’historique restent inexpliquées. P pour liste/Kanban, T pour fiche, C pour récurrence.
5. **Entrée client** : CRM → prospect/contact/entreprise ou société non créée → qualification/reprise/missions → conversion configurée → dossier → matrice onboarding → pièces/étapes manuelles ou verrouillées → accès client contrôlé. Formulaire et configuration observés; conversion, signature et activation du portail restent distinctes, liaison exacte inconnue. P/T/C.
6. **Lettre** : Modèles → importer Word → contrôler variables/options → Vos informations → dossier/missions → compléter → régénérer PDF → figer version → signature → retour/preuve → GED. Parcours documenté; import/génération/signature non exécutés. P pour onglets, T pour propriétés, C pour formulaire.
7. **Temps/charge** : Mes temps → jour → ligne vierge → dossier ou interne → nature → élément ou libellé → durée → Tab/enregistrement → semaine → Temps du cabinet/export → Plan de charge → capacités → détail prévu/réel → réaffectation. Libellé libre et élément restent distincts; aucune règle de capacité supplémentaire inventée. P/T/C.
8. **Collecteur** : Modules → capacité/compte autorisé → dossier/période/portée → collecte de lecture → progression → observations/pièces et couverture → rapprochement → anomalies → reprise au point durable. P pour liste/travaux, T pour résultats sourcés, C pour configuration. Demande, envoi, dépôt et paiement sont des commandes distinctes; aucun portail réel éprouvé ici.

## États et actions réutilisables

| État/action | Présentation et effet à conserver |
|---|---|
| Chargement / vide observé | Réserver la place de la grille; annoncer le chargement. Le vide n’est confirmé qu’avec son périmètre/source. |
| Inconnu / non applicable / zéro | Valeurs textuelles distinctes; aucune cellule vide ou couleur seule ne les fusionne. |
| Refus / lecture seule | Explication contextualisée; propriétés consultables selon droits; contrôle serveur de l’action. |
| Non connecté / indisponible / erreur | Afficher cause, capacité manquante et reprise possible; conserver les résultats antérieurs datés. |
| Modifier / enregistrer | Fiche ou panneau T; validation près du champ; succès après valeur enregistrée; rechargement cohérent. |
| Conflit / aperçu périmé | Préserver la saisie, présenter version courante et résolution; régénérer l’aperçu avant engagement. |
| Travail partiel / reprise | Progression P, portée acquise/manquante, erreurs par objet; absence de fausse réussite globale. |
| Filtrer / sélectionner / exporter | Barre P, propriétés T; conserver périmètre, colonnes, ordre et droits entre liste, détail et sortie. |

## Limites et raccordement local

Le corpus conserve guides, matrice de parcours, catalogue consolidé, inventaire public, démos et journal de vérifications internes. Les preuves privées restent privées; aucun compte, identifiant de session, capture ou code Teradion n’est reproduit. Les seules observations d’écriture abouties concernent une tâche fictive et ses exports; les formulaires annulés, configurations et démos ne prouvent pas leur enregistrement ni les autres rôles.
