# Carte des templates réellement intégrés — candidat Task13

Cette carte couvre les routes et sous-écrans actuellement montés. Elle ne déclare ni le produit complet ni les 160 exigences reçues. Les contrôleurs métier, schémas, commandes, permissions, documents, historiques et identités Memlia restent leurs fournisseurs uniques. Les sources, licences et empreintes exactes sont dans [la provenance](design-interface-provenance.json) ; la distribution est décrite dans [les licences frontend](frontend-licensing.md).

## Limites de preuve et réception

Le harness de navigation de référence rend des modules Plane originaux inchangés avec providers fictifs déclarés. Le harness Propel rend le paquet0.7.3. Ce ne sont pas des applications complètes ; les captures officielles publiées complètent l'observation sans prouver le runtime exact. Les captures Memlia sont remplies avec données fictives, en1440×1000 et900×1000, clair/sombre ; erreurs/lecture seule/vide/chargement/focus/défilement font partie du reçu privé. Chaque série demeure immuable et identifie WIP ou commit. La réception Task13 et la CI exacte appartiennent au contrôleur ; Task12 garde la réception finale de tout le produit.

La branche source d’aperçu temporisé de ResizableSidebar est conservée, mais aucun déclencheur de rail global Plane n’est monté dans cette intégration : elle n’est pas revendiquée comme parcours vérifié. Le repli courant suit la sidebar originale (CSS0, réouverture dans le header), sans rail52 recomposé.
